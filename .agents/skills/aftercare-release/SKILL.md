# Aftercare Release

Read `docs/10-deployment-operations.md`, `docs/12-demo-and-submission.md` and `docs/09-milestones.md`. Audit free plan billing and any automatic pay-as-you-go transition before deployment; do not spend money or authorize upgrades. Configure Sprite services, secure public URL, migrations/backups, connector grants and evidence. Confirm genuine Sprite-hosted agent + connector, restart recovery and honest monitoring mode. Prepare README, public code, demo, LinkedIn @flydotio post and submission by deadline. Final report includes URLs, verified tests, cost, blockers and secrets scan.

## Output required
Report implemented artifacts, changed files, tests executed, exact remaining risks, and the milestone exit result.
