# Aftercare Ui Ux

Read `docs/07-ui-ux-design-system.md` plus relevant product flows. Produce a coherent consumer-grade design (midnight ink + mineral teal, off-white, restrained editorial typography, protection rings/timeline motifs), not a generic dashboard. Start from navigation and key journey, then implement real screens and component states. Review 360/390/768/1024/1440px; keyboard-only and accessibility; dark/light and reduced motion. Never show fake savings, mocked live status, or citations without source. Capture and inspect screenshots; fix visual issues as bugs, not optional polish.

## Output required
Report implemented artifacts, changed files, tests executed, exact remaining risks, and the milestone exit result.
