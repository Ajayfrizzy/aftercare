# Local recovery implementation

Schema 8 backfills durable observation jobs and queues new observations transactionally. While the API is awake it checks due work. The local recovery flow links an issue to its observation, versions a user-editable draft, binds ten-minute approval to the recipient, body, case and version, supports revocation and records single-use export plus a seven-day follow-up date. No external delivery adapter is enabled.

The integration test reopened SQLite after a lease was claimed, verified that work resumed after expiry, created a draft, approved and exported it, and rejected reuse of the approval. The test simulates lease abandonment; a real Sprite crash and remote outcome reconciliation remain unverified. Follow-up notification delivery, activity UI, end-to-end recovery browser coverage and bounded failure retries remain outstanding.
